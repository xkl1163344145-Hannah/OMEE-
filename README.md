# OMEE 空间大师：统一重写基础 0.1.0

本仓库重写历史多套编辑器/SaaS拼接中的核心数据与业务层，目标是一个账号、多个工作空间、同一项目设计和客户确认，并自由选择自购或平台购。**这是开发验收版本，不是V2.0全量生产系统。**

- [系统数据关系与业务边界](docs/系统数据关系.md)：各子系统、数据所有权、实体图、状态机、迁移规则。
- [历史代码审计](docs/历史代码审计.md)：19份代码归档的定位与具体问题。
- [验证报告与剩余开发](docs/验收报告.md)：已验证和待验收分开列出。
- [API契约](docs/API.md)、[部署与恢复](docs/部署与恢复.md)。

## 本地运行

需要Node.js 24+。首次运行：

```bash
npm ci
npm run build
# 在当前shell安全设置SEED_ADMIN_USERNAME和SEED_ADMIN_PASSWORD（密码至少12位）
# 不提供默认弱口令。已存在用户时初始化不会覆盖账号。
npm start
```

默认仅监听`127.0.0.1:3000`，浏览器打开`http://127.0.0.1:3000`。环境变量由shell/进程管理器注入，`.env.example`不会自动加载。生产必须HTTPS+`SECURE_COOKIES=true`，设置`NODE_ENV=production`后缺Secure配置会拒绝启动。

管理员可开通其他独立账号、注册供应商主体；个人所有者/企业管理员建立客户档案与项目。企业管理员在成员页发邀请，成员登录接受后才生效。项目卡片可转派给设计师；设计师只可访问分配给自己的企业项目。

产品与模型页依次建立系列→上传GLB（可选）→SKU→供给，供给需引用已注册的供应商ID。供应商ID可在总控查询。价格以分、尺寸以mm录入。项目中添加SKU、画墙/拖角、调整高度、保存并提交。客户用自己的账号登录“客户审阅”，分别确认设计和BOM；设计师终审后，客户可自购导出CSV，或创建待付款平台订单。

没有接入正式支付。沙箱HMAC回调只有设置`SANDBOX_PAYMENT_SECRET`后才启用，无浏览器“伪付款完成”按钮。Three.js原材质加载器仅支持自包含GLB；没有真实大模型样本，不能宣称完成100MB+模型保真验收。

## 测试

```bash
npm test
npx playwright install chromium
npm run test:e2e
```

E2E启动隔离临时数据目录，不读取生产数据。生成浏览器报告与截图在playwright-report和test-results。运行环境需要可用的Chromium与本地TCP监听权限。

## 技术取舍

当前使用Node24原生HTTP、SQLite事务和Three.js，前端为原生ES模块。选择它是为了先交付可运行的领域约束与回归证据；它不是规格书建议的React/TypeScript/PostgreSQL生产架构。没有复制旧端口服务，也没有自动迁入不明归属的历史数据。后续生产化迁移须保留租户权限、不可变快照、可信核价、支付幂等等约束。
